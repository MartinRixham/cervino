Cervino

Alpine Linux with the GNOME desktop, ready to go. Boot it from a USB stick and you're straight into a full desktop. Install it if you like it.

A small system that feels like a big one

Alpine Linux is known for being small, simple and secure, but setting it up as a desktop takes some work. Cervino does that work for you: it's Alpine with GNOME and everything you'd expect from a desktop already set up.

🖥️

Straight to the desktop

No setup questions before you can try it. Start the computer from the USB stick and GNOME opens, already logged in.

💾

Install in a few clicks

Liked what you saw? Open Install Alpine Linux from the app grid, answer a few questions, and keep the same desktop on your disk.

📦

Apps when you want them

GNOME Software shows Alpine's own apps, and Flathub is set up, so thousands more are a click away.

🛡️

Locked down by default

A firewall is on, nothing listens for remote logins, and the system's background services are kept in their own boxes with AppArmor.

🔌

The everyday things just work

Wi-Fi, Bluetooth, printers, sound, automatic time and power profiles are all ready when you are.

🍓

Runs on a Raspberry Pi too

The same desktop comes as an SD card image for the Raspberry Pi 4, 400, 5 and 500.

Try it

You'll need a USB stick (or an SD card for a Pi) and a computer with plenty of memory: Cervino runs entirely from RAM until you install it.

  1. Download

    Get the latest image from the releases page: the .iso file for a regular PC, or the .img.gz file for a Raspberry Pi.

  2. Write it to a USB stick or SD card

    Use a tool like balenaEtcher, Raspberry Pi Imager or GNOME Disks. You can also open the ISO in a virtual machine.

  3. Start your computer from it

    Pick the USB stick in your computer's boot menu. A minute or so later you're looking at GNOME.

  4. Install it, if you like

    Open Install Alpine Linux, choose a disk and create your account. After a restart, log in and carry on.

Memory: a PC needs about 6 GB of RAM or more to run the live system; a Raspberry Pi needs 8 GB. Installing wipes the disk you choose, so back up anything you want to keep first.

Tested every time

Each new version is booted in a virtual machine, installed to a disk and put through a set of automatic checks: that the desktop starts, that its features work, and that logging out and in again behaves. A release is only published when every check passes.

Want to build your own, with your own user name or browser? Everything you need is in the project's README.
